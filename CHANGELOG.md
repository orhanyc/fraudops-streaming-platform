# Changelog

## 0.1.1 - 2026-10-20

- Fixed the container build so model artifacts are mounted at runtime rather than copied into the image.

## 0.1.0 - 2026-10-20

- Added reproducible synthetic payment generation and chronological evaluation splits.
- Added leakage-safe online features, a logistic baseline and a calibrated gradient-boosted model.
- Added one-percent alert-budget metrics, bootstrap intervals and drift exercises.
- Added FastAPI scoring, an analyst queue, evidence-linked summaries and Prometheus metrics.
- Added Redpanda publishing and consumption with SQLite or PostgreSQL persistence.
- Added Docker Compose, CI, strict typing, tests, security documentation and benchmark reports.
